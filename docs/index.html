1. 准备服务器

准备至少 4 核 CPU、8 GB 内存、部署目录所在文件系统总容量 100 GB 的 Linux 主机。服务器需要能访问镜像仓库 GHCR 和 Docker Hub。

将 Workbench、Studio 和自建对象存储的域名解析到服务器，并在安全组和主机防火墙放行入站 TCP 80、443。使用云厂商的对象存储时可以省略 Storage 域名。

2. 上传并启动安装器

下载上方的 deploy.sh。首次部署时，在 Termius 的 SFTP 面板创建专用目录 /home/aos-work 并上传脚本。已有部署继续使用原目录。在服务器终端运行：

sudo bash /home/aos-work/deploy.sh

安装器在 Host preflight 中显示 CPU、内存、磁盘总量与可用空间，并报告本机 80、443 端口是空闲、由 Nginx 监听还是有冲突。若提示缺少依赖，核对后输入 y 并回车。遇到 [WARN] 时先阅读对应行。

3. 配置域名并部署服务

  1. 主菜单选 1。在子菜单选 1 配置 Workbench、2 配置 Studio、3 配置本机对象存储。每次只填写对应域名，等待 HTTPS 配置保存。安装器会从部署主机经 DNS 分别探测 HTTP 和 HTTPS。
  2. 输入 0 返回主菜单，选 2 打开部署包列表。输入 1 选择第一项。视频录制时的首项是 v2026.11.19，本次发布的安装器首项为 v2026.11.19.1。
  3. 主菜单选 3，子菜单再选 3 同时部署 Studio、Workbench。按提示选择 PostgreSQL、Redis、RabbitMQ 和对象存储的本地或外部模式，并填写凭据。
  4. 中间件就绪后，安装器继续部署 Studio 和 Workbench。按提示设置 Studio 数据加密密码及 Workbench 新建或重置用户的默认密码。单机部署的 Stable sandbox host ID 填 0。
  5. 看到服务的健康检查通过后，分别打开 Studio 和 Workbench 的 HTTPS 地址，确认登录页可以访问。

4. 查看状态与维护

主菜单选 6 查看状态。常驻服务应为 running，配置了健康探针的服务应为 healthy。一次性初始化任务 workbench-storage-init 成功退出时显示 exited。最后核对汇总行 All healthy。

更新服务版本使用主菜单 4，重启服务使用主菜单 5。查看版本说明和离线安装包。
