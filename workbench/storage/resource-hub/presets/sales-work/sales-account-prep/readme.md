## Skill Structure

`SKILL.md` defines account research and call preparation. `user_preferences.md` records optional output choices.

## Modification Map

Change evidence categories, call planning, or result sections in `SKILL.md`. Keep company-specific playbooks outside the reusable package.

## Modification Rules

Preserve fact-versus-hypothesis labels and prohibit CRM or messaging side effects. Do not add personal data enrichment without a separate reviewed capability.

## Common Change Recipes

Add an industry lens as a reusable question set. Add a meeting type by changing objectives and call flow while retaining the evidence ledger.

## Validation

Run the Workbench Skill validator and test with sparse account evidence, conflicting public sources, and a meeting with unknown participants.
