## Skill Structure

`SKILL.md` contains NDA intake and controlled research triage. `user_preferences.md` holds optional presentation preferences.

## Modification Map

Change issue categories and routing in `SKILL.md`. Add playbook clauses or jurisdiction rules only as dated, attributable references.

## Modification Rules

Preserve the no-legal-opinion boundary, qualified-counsel review, source dating, and signature confirmation gate. Do not embed private agreements or client details.

## Common Change Recipes

Add a clause category to the deviation table. Add a research source class by defining authority, date, and conflict-handling rules.

## Validation

Run the Workbench Skill validator and test with an NDA missing governing law, a clause outside the supplied playbook, and conflicting sources from different dates.
