# Library 业务背景

仅在业务对象或意图不清时读取。确定意图后按 SKILL.md 对应能力契约执行初始化、确认、验证和交付；本文不新增 API 或授权。

## 对象与关系

| 对象 | 业务含义 |
| --- | --- |
| 文件／资源 | 被管理的图片、视频、文档等文件资产；名称、目录位置与业务属性是不同信息。 |
| 文件夹 | 组织资源的层级目录。目录位置不等于 Metadata 分类，移动文件也不等于修改标签。 |
| Metadata 字段 | 一种资源业务属性的定义，包含名称、类型、说明及可能的枚举选项；具体定义以当前环境返回为准。 |
| 资源字段值 | 某个文件在某个 Metadata 字段上的实际取值；修改或移除该值与修改、删除字段定义是不同操作。 |
| 标签 | Metadata 的一种展示和取值方式；使用预设选项还是自定义值由实际字段配置决定，不能一律按任意文本处理。 |

空间、目录、路径的解析与权限边界见 [directory-context.md](directory-context.md)，本文不另设默认空间。能查看不代表能下载、编辑、移动或删除。

## 操作含义

- **查找**：关键词表达检索内容，目录限定位置，Metadata 表达业务属性。按 [search.md](search.md) 获取当前字段并映射语义；不把示例字段、目录或枚举当作租户预设。命中结果仍须按该契约检查是否满足用户要求。
- **查看详情**：读取指定资源的信息及元数据，不改变资源。
- **上传**：向目标目录加入文件；**重命名**改变名称；**移动**改变所在目录。这些动作不隐含修改业务分类。
- **修改元数据**：修改文件的业务属性值，不等于修改文件内容或字段定义。值写入和新建 LITE 字段使用 [metadata.md](metadata.md)，字段发现使用 [metadata-catalog.md](metadata-catalog.md)；当前路由未提供字段定义的修改或删除能力。
- **删除资源**：针对文件或文件夹；与移除资源字段值、删除字段定义、清除搜索条件分别处理。删除范围和版本要求遵循对应文件／文件夹契约，不推断级联行为。

## 易混意图

| 用户表达 | 判别依据 |
| --- | --- |
| “把素材归为宣传资料” | 根据上下文区分修改业务属性与移动到文件夹；仍无法确定时先澄清，不能自行选一种写操作。 |
| “删除这个标签” | 区分移除某文件上的字段值、删除字段定义或清除查询条件。尤其不能把移除一个选项直接等同于删除整个字段值；以能力契约支持的粒度处理。 |
| “找品牌素材” | 从当前字段定义及用户语境判断“品牌”的含义；不自动创建同名字段，也不假定存在固定选项。 |

目标和操作明确时直接执行，不增加固定澄清步骤；对象名称不授权新接口或额外写入。
